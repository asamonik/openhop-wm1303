START WITH THE RIGHT HARDWARE

A new chapter for
your SenseCAP M1.

The reference setup pairs a Raspberry Pi 4 with a WM1302/WM1303 HAT and an SX1261 companion radio.

Check the hardware guide ↗
Reference platform
SenseCAP M1 / Raspberry Pi 4
Concentrator
SX1302 or SX1303
Companion radio
SX1261 in the tested setup
Operating system
Raspberry Pi OS Lite
Bookworm or newer
Access
SSH + internet connection

A companion radio is required for channel activity detection. RAK2287-based hotspots are incompatible; other boards may need SPI and GPIO adaptation.

FROM HARDWARE TO FIRST HOP

Up and running.
One step at a time.

The same bootstrap command handles a fresh installation or an upgrade, preserving existing settings.

  1. 01

    Prepare your Pi.

    Install Raspberry Pi OS Lite, connect an antenna, enable SSH, and check the prerequisites.

  2. 02

    Install or upgrade.

    Run the bootstrap command over SSH. A fresh install guides you through the region and channel preset.

  3. 03

    Meet your Manager.

    Open http://<pi-ip>:8000/wm1303.html on your local network, sign in, and configure your channels.

INSTALL / UPGRADE
curl -fsSL https://raw.githubusercontent.com/asamonik/openhop-wm1303/main/bootstrap.sh | sudo bash

Run only on compatible hardware. Review the installer or follow the full installation guide.
