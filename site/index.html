OpenHop WM1303

A LoRa bridge and repeater for MeshCore on WM1302/WM1303 hardware.

GitHub Documentation

Requirements

  • SenseCAP M1, or a compatible Raspberry Pi 4 with a WM1302/WM1303 HAT and an SX1261 companion radio.
  • Raspberry Pi OS Lite (Bookworm or newer), with SSH enabled.
  • A connected antenna and internet access.

RAK2287-based hotspots are incompatible. For other boards, check the hardware guide.

Install or upgrade

Run over SSH on the Pi:

curl -fsSL https://raw.githubusercontent.com/asamonik/openhop-wm1303/main/bootstrap.sh | sudo bash

Follow the prompts to select your region and channel preset. Upgrades preserve existing settings. If the installer requests a reboot, run sudo reboot.

Full installation guide

Open the Manager

  1. Open http://<pi-ip>:8000/ on your local network to complete setup and sign in.
  2. Open http://<pi-ip>:8000/wm1303.html on the same host.
  3. Configure and enable the channels you need, then set your bridge rules. All channels start disabled on a fresh install.

Service and logs

sudo systemctl status openhop-repeater
journalctl -u openhop-repeater -f
